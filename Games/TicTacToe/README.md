# Tic Tac Tactics

An innovative Tic Tac Toe game built with React, TypeScript, Vite, Tailwind CSS, Motion, and Vitest.

## Features

- Classic local two-player mode
- AI mode with Easy, Medium, and Impossible levels
- Power mode with Freeze, Swap, Undo Pulse, and Wild Cells
- Animated board and result states
- Replay-style move timeline
- Local stats for wins, draws, games, and streaks
- Unit-tested game engine and AI decisions

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run build
```
